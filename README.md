# OpenCora

Internal enterprise AI-powered development tool for code exploration, refactoring, and pair programming.

## Getting Started

### Local Setup

To run OpenCora locally in development mode:

1. Install dependencies:
   ```bash
   bun install
   ```

2. Start the local developer server:
   ```bash
   bun dev
   ```
